## ADDED Requirements

### Requirement: 注册参考脸与唯一替换脸

系统 MUST 递归读取 `source_face` 中的静态参考图片，要求至少一张有效参考图且每张恰好包含一张脸；参考集合可以覆盖同一人的多个角度或多个身份。系统 MUST 要求 `target_face` 中恰好有一张有效静态图片且恰好有一张脸。候选图片损坏、无脸、多脸或类型不支持 MUST 在预检查中报告并失败，不隐式选择第一张脸或第一张图片。

#### Scenario: 注册多个参考身份
- **WHEN** 参考目录包含多张有效单脸图片，分别代表一个或多个人
- **THEN** 所有参考特征进入同一个匹配集合，任意参考身份命中均使用同一替换身份

#### Scenario: 参考图中有两张脸
- **WHEN** 一张候选参考图检测到两张有效人脸
- **THEN** 系统报告该文件并在素材处理前退出

#### Scenario: 参考目录为空
- **WHEN** 参考目录没有有效候选图片
- **THEN** 系统报告参考集合为空并退出，不把全部素材作为未匹配处理

#### Scenario: 替换目录中有多张有效图片
- **WHEN** 替换目录包含两张有效单脸图片
- **THEN** 系统要求明确唯一替换图，不自动选取其中一张

### Requirement: 参考特征预先计算

系统 MUST 在处理素材前提取并 L2 归一化参考与替换特征，校验特征非零、有限且维度符合模型要求，并在本次运行中复用。替换身份的 INSwapper 映射特征 MUST 提前计算并复用。

#### Scenario: 处理多个视频帧
- **WHEN** 一次运行连续处理多个素材或帧
- **THEN** 不重复读取参考图片、加载参考模型或计算替换身份映射

#### Scenario: 特征为无效向量
- **WHEN** 注册或素材特征提取返回零向量或非有限数值
- **THEN** 系统报告特征错误，不参与距离比较或产生换脸结果

### Requirement: 使用最小归一化欧氏距离匹配

系统 MUST 在原始帧上提取素材人脸的归一化特征，与全部参考特征计算欧氏距离，以最小距离严格小于 `thresholds` 为匹配条件。初始默认值 MUST 为 `1.25`，并明确说明该值待实际素材校准。系统 MUST 记录最近参考与距离，不将其解释为概率。

#### Scenario: 命中任意参考图
- **WHEN** 一张素材脸与两个参考特征的距离为 `1.30`、`1.10`，且阈值为 `1.25`
- **THEN** 该脸匹配第二个参考特征并执行一次替换

#### Scenario: 距离等于阈值
- **WHEN** 最小距离等于配置阈值
- **THEN** 该脸不匹配，不执行换脸

### Requirement: 一帧替换全部匹配人脸

系统 MUST 先基于原始帧确定全部匹配结果，再逐个将匹配脸替换为指定身份。每张素材脸 MUST 最多替换一次，未匹配脸 MUST 不进入换脸流程。系统 MUST 保留 INSwapper 对齐、身份映射、通道和融合语义，不在首个命中后结束本帧。

#### Scenario: 同帧两张脸命中
- **WHEN** 三张素材脸中两张匹配参考集合，另一张不匹配
- **THEN** 两张匹配脸都替换，另一张不作为替换对象，并记录两次成功换脸

#### Scenario: 一张脸命中多个参考图
- **WHEN** 同一张素材脸与多张参考图的距离都小于阈值
- **THEN** 仅执行一次换脸，并保留最小距离的参考信息

### Requirement: 换脸后仅增强成功替换的人脸

启用增强时，系统 MUST 在本帧全部换脸完成后，对成功替换的人脸区域使用 GFPGAN 专用五点模板对齐、执行 `512×512` 增强并逆变换融合。系统 MUST 使用 `enhance_blend` 控制增强结果与换脸后区域的融合比例，不把该参数当作 GFPGAN 内部 `weight`；未替换脸不进入增强流程。禁用增强 MUST 输出换脸结果，不加载增强模型。

#### Scenario: 匹配脸与未匹配脸同框
- **WHEN** 一帧有一张成功换脸的人脸和一张未匹配人脸，增强已开启
- **THEN** 仅成功换脸的人脸区域接受增强，不运行整帧人脸增强

#### Scenario: 禁用增强
- **WHEN** `enhance_enabled=false`
- **THEN** 匹配脸执行换脸后直接进入输出，不要求 GFPGAN 权重存在

#### Scenario: 增强失败
- **WHEN** 已换脸的人脸在增强推理中失败
- **THEN** 当前文件报告失败，不发布仅换脸结果并宣称换脸和增强成功

### Requirement: 无匹配帧与增强噪声稳定

系统 MUST 对正常检测但未匹配的帧直接复用原帧，不运行换脸或增强。GFPGAN 视频推理 MUST 使用固定噪声模式，并保证其随机噪声配置不会逐帧重新生成；系统不能因此宣称具备完整时序跟踪能力。

#### Scenario: 帧中所有人脸都不匹配
- **WHEN** 所有检测脸的最小距离都不小于阈值
- **THEN** 帧像素保持原样，换脸与增强调用数量均为零

#### Scenario: 相同对齐脸重复增强
- **WHEN** 对同一对齐输入重复执行相同后端的增强推理
- **THEN** 不因新生成的随机噪声产生不同纹理，数值比较使用该后端约定的容差
